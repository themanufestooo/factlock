# @veritas/merkle-log

RFC 6962 Merkle transparency log for the Veritas attestation protocol (T4).

- `leaf_hash = SHA256(0x00 || leaf)`, `node_hash = SHA256(0x01 || left || right)`
- Leaves are JCS-canonical attestation bytes (see `appendAttestation`, which
  canonicalizes with the T1 reference library `@veritas/attestation-core`).
- Append-only, in-memory tree with O(log n) inclusion proofs; optional JSONL
  journal for persistence and third-party audit.
- Anchoring the root on-chain is T5 (out of scope here).

## Install

```sh
npm install   # pulls @veritas/attestation-core via file:../core-ts
npm run build
```

## Use

```ts
import { MerkleLog, verifyInclusionProof, verifyConsistencyProof } from "@veritas/merkle-log";

const log = new MerkleLog("./data/veritas-main.jsonl"); // journal optional

const { index, root } = log.appendAttestation({
  attestation_id: "vat_01K5EXAMPLE",
  claims: [{ type: "price", service: "service_call", amount_minor: 8900 }],
});

const proof = log.getProof(index);          // { leaf, index, size, path, root }
verifyInclusionProof(proof);                // true — pure function, no server needed

const cp = log.getConsistencyProof(100, 250); // old tree is a prefix of new tree
verifyConsistencyProof(cp);                  // true

log.getRoot();                              // current root, hex
```

## Scripts

- `npm test` — 71 tests: cross-language vectors (`packages/vectors/merkle-vectors.json`,
  generated by `generate-merkle.py` with Python hashlib) plus behavior tests.
- `npm run bench` — builds 1M leaves, times 2,000 random proofs.
  Acceptance: proof p99 < 50 ms. Last run: p99 ≈ 0.04 ms.
- `node dist/scripts/audit-log.js <log.jsonl> [expected-root-hex]` — third-party
  audit: replays the journal from scratch and recomputes the root. Exit 0 on
  match, 1 on mismatch.

## Proof formats

Inclusion path entries are ordered leaf-up: `{ hash, left }`, where `left`
means the sibling hash goes on the left when recombining. The `index` field is
metadata — the proof attests that *the leaf* is in the tree.

Consistency proofs carry the perfect aligned blocks partitioning `[0, newSize)`,
split at `oldSize`; both roots recompute from the blocks via `foldBlocks`
(recursive RFC 6962 split at the largest power of two < total).

## Notes

- `@veritas/attestation-core` is consumed as `file:../core-ts` until published;
  reinstall `log-ts` after rebuilding `core-ts`.
- The journal is append-only and crash-tolerant per line; `MerkleLog.load(path)`
  resumes appending, `MerkleLog.replay(path)` audits without attaching.
